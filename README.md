Nykaa YouTube Content Analysis

I pulled every video (720) from Nykaa's official YouTube channel using the YouTube Data API and looked at what actually gets views vs. what gets people to engage. This was done for my "Be The Face of Nykaa" entry, to back up my GRWM with something more than just a video.

What's in here:
nykaa-tables-analysis.docx — full breakdown, table by table, with plain-language analysis after each one
Nykaa_analysis.ipynb — the script that pulled and processed the data

Quick summary: Long tutorials pull the most views. Short reviews pull the most genuine reaction (likes/comments per viewer). Right now, nothing on the channel is doing both at once — which is the gap my 5 video ideas are built around.

Limits: this is public data only, no internal Nykaa numbers. Content categories are based on keyword matching in titles/descriptions, spot-checked but not perfect. Can't tell which videos were paid promotion, which would skew the "top performer" numbers.
